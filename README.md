## 🌟 Overview
A responsive web application that generates personalized affirmations and color palettes based on user identity and emotional input. This project focuses on **User Personalization** and **DOM Manipulation**.

## 🚀 Live Demo
**Link:** [https://kpriyars.github.io/PERSONALISED-MOOD-PALETTE/](https://kpriyars.github.io/PERSONALISED-MOOD-PALETTE/)

## ✨ Key Features
- **Identity Personalization**: Addresses the user by name in every affirmation.
- **Dynamic Mood Map**: A scalable JS object mapping moods to colors.
- **Glassmorphism UI**: High-end frosted glass card effect.
- **Birthday Mode**: A secret "Easter Egg" for celebrations! 🎂

## 🛠️ How it Works
1. The script captures the `name` and `mood` from input fields.
2. It uses **Template Literals** to merge the name with a specific affirmation.
3. It updates the `document.body.style.background` to match the mood color.

## 📂 Project Structure
- `index.html` - Semantic structure & UI inputs.
- `style.css` - Custom styling & smooth 0.8s transitions.
- `script.js` - Logic, data mapping, and personalization.
